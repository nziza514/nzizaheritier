# Nziza Heritier — Personal Website

A responsive, multi-page cinematic portfolio for Rwandan filmmaker, cinematographer, director and editor Nziza Heritier.

## Pages
- `index.html` — cinematic landing page and introduction
- `about.html` — biography, studio profile and services
- `work.html` — selected work gallery
- `contact.html` — direct and studio contact details

## Personalizing the site
The current site uses the GitHub profile image as a portrait fallback and curated Unsplash imagery for the visual placeholders. Replace the image URLs in `styles.css` with your own optimized photos when ready. The Imiringa Productions mark is an original typographic SVG included at `assets/imiringa-mark.svg`; replace it with the official logo when available.

The layout is static, responsive, accessible, and optimized for GitHub Pages: no build step or framework is required. Set GitHub Pages to deploy from the `main` branch root.
